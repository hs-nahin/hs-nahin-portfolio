# Hasnat Shahriyar - Developer Portfolio

A modern, terminal-themed portfolio website built with Next.js 15, showcasing skills and projects in a unique VS Code-style interface.

## 🚀 Features

- **Terminal Interface**: Complete VS Code-style terminal with file tree navigation
- **Magic UI Components**: Custom cursor, particles, meteors, and smooth animations
- **Responsive Design**: Mobile-first approach with proper breakpoints
- **Dark/Light Theme**: Global theme toggle with consistent styling
- **Interactive Elements**: Hover effects, transitions, and micro-interactions

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **UI Components**: Custom Magic UI components
- **Icons**: Lucide React
- **Animations**: CSS animations and transitions
- **Theme**: next-themes for dark/light mode

## 📁 Project Structure

```
portfolio/
├── about.md          # Profile and introduction
├── skills.js         # Technical skills showcase
├── projects/         # Project portfolio
│   ├── CodeLink.jsx  # Collaborative developer platform
│   └── CareerHive.jsx # Job board platform
└── contact.tsx       # Contact form and information
```

## 🎨 Design Features

- Gradient blue theme (from-blue-900 to-blue-500)
- Custom cursor with dot and ring effects
- Particles background animation
- Typewriter animation for name display
- Spinning text around profile image
- Meteors animation in contact section
- Shine border effects on interactive elements

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Open [http://localhost:3000](http://localhost:3000)
